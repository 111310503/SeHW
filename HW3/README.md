# LocalLeadPulse — 在地商家口碑商情與顧客流失挽回引擎

> **定位**：專為實體門市（餐飲、旅宿民宿、診所、零售）打造的自動化數位聲譽健檢、客訴自動公關防護與流失營收量化分析系統。

---

## 💡 為什麼這個專案具有極高的「商業價值」與「使用價值」？

### 1. 商業價值（如何獲利與接案變現？）
* **清楚的商家痛點**：店家普遍知道「Google 負評很痛」，但多數老闆不知道「一則負評到底讓他們少賺多少錢」，更沒有時間與公關文筆逐一妥善回覆。
* **變現路徑 A：一次性商譽診斷顧問案（單案 NT$ 8,000 ~ 25,000）**
  * 使用此工具抓取店家近 3 ~ 6 個月評論，產生 `client_audit_report.md`。
  * 提供「流失營收評估報告書」與「改善行動清單」，店家對能直接看到損失金錢（例如：*預估一年流失 86,400 元*）的報告極為買單。
* **變現路徑 B：月費制聲譽監控代操 (Retainer NT$ 1,500 ~ 3,500 / 月)**
  * 定期自動掃描商家負評。
  * 遇到 1~2 星差評或衛生問題時立即發送公關回覆建議草稿，保護商家平均星級維持在 4.5 星以上。
* **變現路徑 C：白牌 SaaS 軟體服務**
  * 串接 Google Places API / Google Business Profile API，包裝成 Web Dashboard 提供中小企業訂閱。

### 2. 使用價值（自己或身邊的人就能直接使用）
* 如果您自己有經營個人品牌、電商、蝦皮賣場、或是幫親友的實體店鋪做行銷，這套系統能：
  1. 一鍵找出店裡最常被客訴的死角（例如：「態度差」佔比最高？還是「出餐慢」？）。
  2. 遇到奧客或爭端時，系統自動產出**不卑不亢、具備同理心的高情商公關回函**，省去老闆自己生氣想文字的時間。
  3. 量化顧客終身價值 (LTV)，讓管理階層具體感受客服投資的投資報酬率 (ROI)。

## ⚙️ 核心演算法與財務模型

### 1. 顧客終身價值與流失損失公式 (Customer LTV Loss Model)
$$
\text{LTV} = \text{平均客單價 (Ticket Size)} \times \text{每年平均回訪次數 (Annual Frequency)}
$$

$$
\text{預估商譽損失金額} = \text{高風險客訴數} \times \text{負面外溢擴散係數 (2.5)} \times \text{LTV}
$$

*每一則未妥善處置的差評，平均會影響該顧客本人與 1.5 位親友的回訪意願。*

### 2. 評級機制
* **HIGH (高危緊急)**：評分 $\le 2$ 星或涉及食品安全、衛生、辱罵爭端。
* **MEDIUM (中度注意)**：評分 3 星或性價比、等待時間微詞。
* **LOW (優良滿意)**：4~5 星正面反饋。

## 🏃 快速執行教學

### 環境需求
* 僅需 **Python 3.8+**，使用內建模組（無需安裝額外龐大的第三方套件，輕量快速）。

### 執行步驟
```bash
python locallead_pulse.py
```

### 執行產出
1. **終端機即時圖表**：包含星等、財務風險統計與問題分類長條圖。
2. **自動生成診斷檔案**：系統會在當前目錄輸出 `client_audit_report.md`，可直接轉換為 PDF 或列印成商業簡報提交給業主。
