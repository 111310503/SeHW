# LeadScraper & AuditPulse — 在地商家數位體質審計與 B2B 接案潛在客源獲利引擎

> **專案定位**：專為數位游牧者、接案軟體工程師、網頁設計工作室與數位行銷人打造的「**主動開發高成交機率店家與自動化產出商業診斷書**」的獲利輔助工具。

---

## 💎 本專案的真實價值

### 1. 商業價值（如何獲利 / 接案變現？）
* **打破接案開發盲區**：多數人接案都去外包網（如 104、Tasker）削價競爭。但高利潤的案子通常來自「**主動向實體店家指出盲點，並提供完整解決方案**」。
* **精準鎖定「黃金級客戶」**：
  * **特徵**：店家本身生意好（Google 評分 $\ge 4.5$ 星、評論數破百、月營業額穩定），但**竟然沒有官方網站**，或網站建於十年前、沒有手機版、沒有 HTTPS 安全憑證。
  * **痛點**：這類店家極度害怕客人跑掉，且每年被外送平台或 OTA 訂房網抽成 15%~30%，他們渴望有自己的獨立官網與預約系統。
* **高溢價提案工具**：
  * 使用本程式一鍵產出客製化診斷書 `PROPOSAL_店家名稱.md`，內容包含「體質得分、漏洞清單、預估損失、解決方案報價」。
  * 拿著這份專業報表直接拜訪或寄給老闆，平均成交單價落在 **NT$ 35,000 ~ 65,000**（官網重構 + 在地 SEO）。

### 2. 使用價值（實用功能）
* **免外部肥大套件**：純 Python 原生打造，不需安裝肥大相依即可直接運行。
* **客觀多維度評分 (0-100)**：包含 Google 評論熱度、網域名稱安全性、SSL 憑證、行動端 RWD 檢測與社群媒體矩陣連結。
* **商機分級矩陣**：自動區分 A 級（黃金對象）、B 級（成長潛力）、C 級（已成熟無開發價值），大幅節省開發業務時間。

## 📐 數位成熟度指數計算公式

$$
\text{數位成熟度 (Score)} = S_{\text{Google 商家}} (30\%) + S_{\text{品牌官網}} (40\%) + S_{\text{社群經營}} (30\%)
$$

* **Google 商家指標**：
  * 評分權重：$R \ge 4.5 \implies 15$ 分；$R \ge 4.0 \implies 10$ 分；其餘 5 分。
  * 評論數量：$N \ge 150 \implies 15$ 分；$N \ge 50 \implies 10$ 分；其餘 0~5 分。
* **品牌官網指標**：
  * 具備獨立網站：$+20$ 分。
  * 具備有效 SSL (HTTPS) 憑證：$+10$ 分。
  * 符合行動裝置 RWD 規範：$+10$ 分。
* **社群矩陣指標**：
  * 具備 Facebook / Instagram 連動與漏斗：$+30$ 分。

## 🚀 快速上手教學

### 執行環境
* 支援 **Python 3.8+**。

### 執行步驟
在終端機中執行：
```bash
python lead_pulse_auditor.py
```

## 💼 接案 SOP 實戰流程

1. **鎖定商圈**：挑選您所在的市區、老街、觀光區（例如：金門金城商圈、台中勤美草悟道）。
2. **運行掃描**：將名單填入系統跑出 A 級潛在名單。
3. **產出診斷書**：自動產出 Markdown 提案檔案。
4. **接觸客戶**：
   * *「老闆您好，我們在幫在地商家做數位健檢時發現，您的 Google 評價高達 4.7 星但沒有獨立官網，每個月被訂房平台抽走上萬元手續費，我們為您準備了一份免費體質診斷報告，提供給您參考...」*
5. **簽約交付**：執行網站架設與維護合約。
