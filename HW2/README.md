# 國立金門大學 (NQU) 校務整合資訊系統專案

本專案模擬**國立金門大學 (National Quemoy University, NQU)** 校務行政入口網站之核心業務邏輯，以 Python 物件導向 (OOP) 架構設計，具備角色權限控管、選課引擎、成績管理與資料持久化（JSON）。

---

## 📌 功能特色

### 1. 三層角色權限架構 (Role-Based Access Control)
- **學生 (Student)**：
  - 檢視個人學籍資料（學號、姓名、學系、年級）。
  - 全校課程清單查詢。
  - 線上即時加選、退選（具備名額上限與防重複加選檢驗機制）。
  - 個人課表與總修習學分統計。
  - 學業成績單檢閱與自動計算 **4.3 制 GPA**。
- **授課教師 (Teacher)**：
  - 檢視自己所開立的課程清單。
  - 查詢各課程的選課名冊與修課學生修讀狀態。
  - 線上登錄與更新學生期末成績。
- **教務管理員 (Admin)**：
  - 新增開課科目（設定課程代碼、學分、授課老師與人數上限）。
  - 批次開立學生與教師帳號。
  - 掌控全校所有開課與選課名額狀況。

### 2. 資料持久化 (Persistence)
- 系統自動產生並讀取 `nqu_system_data.json` 檔案。
- 選課、成績輸入、建立帳號等操作均會即時儲存至檔案，重新啟動程式資料不遺失。

## 🚀 快速開始

### 環境需求
- Python 3.8+ （本專案使用標準函式庫，無需額外安裝第三方套件）。

### 執行方式
在終端機 (Terminal / Command Prompt) 執行：
```bash
python nqu_portal_system.py
```

## 📊 GPA 換算標準 (4.3 制)

| 成績區間 | 等第對應 | GPA 等級積點 |
| :---: | :---: | :---: |
| 90 ~ 100 | A+ | 4.3 |
| 85 ~ 89 | A | 4.0 |
| 80 ~ 84 | A- | 3.7 |
| 77 ~ 79 | B+ | 3.3 |
| 73 ~ 76 | B | 3.0 |
| 70 ~ 72 | B- | 2.7 |
| 67 ~ 69 | C+ | 2.3 |
| 63 ~ 66 | C | 2.0 |
| 60 ~ 62 | C- | 1.7 |
| 0 ~ 59 | F | 0.0 |

$$\text{GPA} = \frac{\sum (\text{課程學分} \times \text{積點})}{\sum \text{總修習學分}}$$

## 🛠️ 擴充方向建議
1. **Web 前端介面**：可使用 Flask 或 FastAPI 包裝為 RESTful API，並結合 Vue / React 或 Jinja2 網頁樣板打造擬真金大入口網頁。
2. **資料庫遷移**：從 JSON 升級至 SQLite 或 PostgreSQL，結合 SQLAlchemy 進行 ORM 管理。
3. **衝堂驗證**：擴充課程節次欄位（例如：週二第 3、4 節），在學生加選時檢查衝堂機制。
